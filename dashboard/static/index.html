5G / LTE user plane · 3GPP TS 29.281

Every tunnel, every packet, in real time.

gtpu-fwd is a C packet forwarder that validates GTP-U headers, looks up the tunnel endpoint ID, rewrites it and relays the packet to the next hop. This control room shows it working: live counters, per-route traffic, and a lab to break packets on purpose.

          How a packet is handled

          Five checks, one lookup, one rewrite. Anything else is counted and dropped, never crashed on.

          1. 1

            Receive

            recvmmsg pulls up to 32 datagrams per syscall into preallocated buffers.

          2. 2

            Validate

            Version 1, PT bit, length vs. datagram size, then a bounds-checked walk of the extension chain.

          3. 3

            Classify

            Echo Request is answered; G-PDU continues (optionally with an inner IP check); every other type is dropped.

          4. 4

            Look up

            Open-addressing hash table keyed by TEID, O(1), with per-route counters. Unknown TEID: drop, optionally with an Error Indication.

          5. 5

            Rewrite & send

            The 4-byte TEID is overwritten in place and the datagram goes to the IPv4 or IPv6 next hop.
